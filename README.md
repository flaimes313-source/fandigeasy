# Funding Arbitrage Bot

Бот для мониторинга положительного фандинга на бирже Bybit.

## Функционал

- Сканирует все USDT фьючерсы каждые 30 секунд
- Находит монеты с положительным фандингом >= 0.05%
- Проверяет наличие спотового рынка
- Проверяет ликвидность (объем >= 1 млн USD)
- Отправляет уведомления в Telegram
- Рассчитывает потенциальную прибыль с учетом комиссий
- Показывает ROI
